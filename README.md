# Nidhi Sikka — Portfolio

Personal portfolio website of **Nidhi Sikka** — MBA graduate (PCTE, Ludhiana), BBA (HNBGU, Dehradun), schooling at Rainbow School.

## Built with

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com) v4
- [Framer Motion](https://framer.com/motion) for animations

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
